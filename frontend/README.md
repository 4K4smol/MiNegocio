# Frontend MiNegocio

Aplicacion React de MiNegocio para la gestion de clientes, ordenes de trabajo, facturacion, inventario, calendario y administracion.

## Requisitos

- Node.js compatible con Vite 8
- npm

## Instalacion

```bash
npm install
```

Si la API no usa la URL por defecto, configura las variables de entorno necesarias en un archivo `.env.local`.

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

El resultado de produccion se genera en `dist/`.

## Comprobaciones

```bash
npm run lint
npm run preview
```
