# Logo oficial de MiNegocio

Archivos incluidos:

- `minegocio-logo-horizontal-transparente.png`: logo principal para web, presentaciones y documentación.
- `minegocio-logo-horizontal-fondo-blanco.png`: versión recomendada para documentos y fondos claros.
- `minegocio-logo-horizontal-fondo-azul-oscuro.png`: versión preparada para cabeceras oscuras.
- `minegocio-icono-transparente.png`: símbolo principal sin texto.
- `minegocio-icono-fondo-blanco.png`: símbolo sobre fondo blanco.
- `minegocio-icono-32x32.png`, `64x64`, `128x128`, `256x256`, `512x512`: iconos para favicon, app y redes.

Uso recomendado:
- Para la landing pública: usar `minegocio-logo-horizontal-transparente.png`.
- Para Word/PDF/memoria del proyecto: usar `minegocio-logo-horizontal-fondo-blanco.png`.
- Para favicon: usar `minegocio-icono-32x32.png` o `minegocio-icono-64x64.png`.
- Para icono de aplicación: usar `minegocio-icono-512x512.png`.
